# ЕЖЕДНЕВНИК

Персональное PWA-приложение для быстрого сохранения задач, покупок, идей, ссылок, цен и заметок. Главный сценарий: быстро написать или надиктовать текст, получить структурированный preview и сохранить результат.

Живая версия после деплоя GitHub Pages:

https://ver-dikt.github.io/DNEVNIK/

## Стек

- Next.js App Router
- React
- TypeScript strict
- Tailwind CSS
- Supabase-ready schema
- PWA manifest + service worker
- AI provider abstraction: mock и OpenAI-compatible adapter

## Локальный запуск

```bash
npm install
npm run dev
```

Открой `http://localhost:3000`.

## Публикация на GitHub Pages

Деплой настроен через GitHub Actions: `.github/workflows/deploy-pages.yml`.

После push в `main` workflow запускает проверки, делает static export и публикует `out/` на GitHub Pages. Для Pages build используется:

```bash
GITHUB_PAGES=true NEXT_PUBLIC_BASE_PATH=/DNEVNIK npm run build
```

## Environment

Скопируй `.env.example` в `.env.local` и заполни значения.

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
SUPABASE_SECRET_KEY=

AI_ENABLED=false
AI_PROVIDER=mock
AI_BASE_URL=
AI_API_KEY=
AI_MODEL=
```

Ключи AI используются только на сервере в `/api/ai/parse` и `/api/ai/query`.

## Supabase

1. Создай проект Supabase.
2. Укажи `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`.
3. Примени migration из `supabase/migrations/20260820122000_initial_schema.sql`.

Схема содержит:

- `profiles`
- `projects`
- `entries`

Для всех таблиц включен RLS, данные привязаны к `auth.uid()`.

## AI provider

По умолчанию работает `MockAIProvider`, поэтому приложение можно использовать без ключей и баланса.

Для Groq, Qwen, OpenAI или другого OpenAI-compatible API:

```env
AI_ENABLED=true
AI_PROVIDER=openai-compatible
AI_BASE_URL=https://api.example.com/v1
AI_API_KEY=...
AI_MODEL=...
```

Логика выбора провайдера находится в `src/lib/ai-provider.ts`.

## Что работает в MVP

- Главный экран "Сегодня"
- Быстрое добавление
- AI preview перед сохранением
- Local Smart Parser для идей, покупок, задач, ожидания, цен, количества, URL, дат, проектов и confidence
- Разделы: Сегодня, Неделя, Задачи, Проекты, Покупки, Идеи, Inbox, Настройки
- Редактирование заголовка записи
- Завершение задачи с Undo
- Удаление записей
- Локальное хранение в `localStorage`
- Learned rules в `localStorage` (`dnevnik.learnedRules`)
- PWA manifest и базовый offline shell
- Supabase migration

## Smart Parser

Parser находится в `src/lib/smart-parser/`.

Модули:

- `normalizer.ts`
- `tokenizer.ts`
- `intent-detector.ts`
- `date-parser.ts`
- `price-parser.ts`
- `quantity-parser.ts`
- `url-parser.ts`
- `project-matcher.ts`
- `priority-parser.ts`
- `status-parser.ts`
- `entity-extractor.ts`
- `confidence.ts`
- `learned-rules.ts`

Логика `/api/ai/parse`: сначала local parser, затем optional AI fallback только при низкой уверенности и включенном AI provider.

## Надёжность и PWA — сентябрь 2026

- Постоянная кнопка «Добавить» открывает текстовый и голосовой ввод из любого раздела. Поиск включает все записи.
- Черновик и разобранные записи восстанавливаются после перезапуска. Ошибки основного хранилища показываются в интерфейсе; экспорт сохраняет актуальное состояние, включая память исправлений.
- Перед импортом приложение предлагает скачать текущую резервную копию. Поддерживаются старые и новые названия финансовых полей. Импорт заменяет текущий набор данных.
- Приватный режим и очистка данных браузера не обеспечивают долговременного хранения. Облачная синхронизация пока не подключена. Записи разных адресов, портов и браузеров хранятся отдельно.
- На iPhone установленная иконка открывает PWA по прежнему URL. Не удаляйте PWA и данные Safari перед экспортом. Для переноса на другой адрес используйте экспорт/импорт JSON.
- Обновление service worker не перезагружает ввод автоматически. После публикации закройте все окна приложения и откройте его снова; доступное обновление также предлагается в интерфейсе.
- Поддержка диктовки зависит от браузера, разрешения микрофона и службы распознавания. На iPhone при недоступности Web Speech используйте микрофон системной клавиатуры в текстовом поле. Реальное распознавание на физическом iPhone требует проверки на устройстве.
- Локальный запуск: start-local.bat собирает приложение и запускает http://127.0.0.1:3000. Не чередуйте localhost и 127.0.0.1 для ежедневной работы: у них разная память.

### Публикация

На момент проверки https://ver-dikt.github.io/DNEVNIK/ возвращает 404, репозиторий приватный; API конфигурации Pages также возвращает 404. Успешный push или сборка ветки gh-pages сами по себе не включают Pages. Для приватных репозиториев GitHub требует поддерживающий Pages тариф: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages . Приватность репозитория этой доработкой не меняется.

### Проверки регрессий

npm test проверяет в том числе запрет обоих хранилищ, работу IndexedDB без localStorage, сохранение при очистке маркера миграции, импорт старых и новых финансовых форматов, откат неудачной транзакции и русский разбор количества/общей цены.

При анализе аналогов использованы официальные материалы: резервные копии Todoist (https://www.todoist.com/help/articles/115001799989), голосовые записи и экспорт Day One (https://dayoneapp.com/features/). Приоритет этой версии — быстрый ввод, восстановление черновика и переносимость данных.

## Интерфейс и навигация — финальная проверка

- На телефоне: пять постоянных кнопок, все разделы в меню «Ещё». На компьютере: боковая панель, поиск и быстрый ввод.
- Раздел отражается в адресе; работают возврат назад, поиск, переходы из сводки, Ctrl/Cmd K и Ctrl/Cmd Enter.
- Вложенные окна удерживают фокус и закрываются по одному; прокрутка и высота учитывают доступную область экрана.
- Завершение и возврат записи работают из сводки и покупок; задачи показывают активные и завершённые записи. Новая задача получает владельца выбранного фильтра.
- Проверено: 103 автоматических теста, TypeScript, ESLint, production-сборка; в браузере — десять разделов, создание/завершение/возврат задачи, светлая и тёмная темы, мобильное меню и вложенное редактирование. Физический iPhone и реальный микрофон удалённо не проверены.
- GitHub Pages: попытка включения для приватного репозитория отклонена API (422: тариф не поддерживает Pages для этого репозитория). Репозиторий остаётся приватным.
