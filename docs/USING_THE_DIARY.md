# Ежедневник на компьютере, телефоне и в чате

Откройте `Ежедневник.lnk` в основной папке проекта или на рабочем столе.
На компьютере он автоматически запускает ежедневник и установленную Ollama, затем открывает одно окно приложения.
На телефоне используется обычная установленная PWA https://ver-dikt.github.io/DNEVNIK/.
Это один проект и одна облачная база при входе в один аккаунт. `start-dev.bat` и `start-local.bat` используются при разработке.

## Синхронизация

На компьютере и телефоне нажмите «Облако» и войдите в один аккаунт с одной почтой и паролем.
Записи сохраняются в Supabase. Изменения отправляются после редактирования, проверяются при возврате в приложение и примерно раз в 15 секунд, пока окно видно. Если запись уже отправляется, новые изменения становятся в очередь. Неизменившиеся данные повторно в базу не записываются.
Для обмена нужен интернет. При работе без сети записи остаются локально и синхронизируются после подключения.
На компьютере приложение работает по локальному адресу, на телефоне — по адресу PWA; записи объединяются через Supabase.

Второй телефон также может подключиться к этой базе под тем же аккаунтом. Два независимых аккаунта пока получают разные личные базы: приглашение партнёра и совместный доступ между аккаунтами ещё не реализованы.

## Локальная модель на компьютере

Единственный ярлык `Ежедневник` запускает установленную Ollama и приложение на `http://127.0.0.1:3014`. Отдельного запуска «с ИИ» нет.
На широком компьютерном экране справа постоянно открыт «Чат ежедневника». На узком компьютерном окне он сворачивается в панель снизу. Отдельное окно помощника открывать не нужно.
Первый запуск после переноса может потребовать сборку. Модели автоматически не скачиваются, облачные модели Ollama не предлагаются.
Используется установленная Qwen3.5:9b без выбора модели и режима. Пишите обычным языком: чат сам различает вопросы, новые записи и команды изменения. Он получает актуальные записи всего ежедневника и недавнюю переписку, поэтому разговор продолжается между разделами.
Например: «Перенеси задачу Покрасить стены в Дом / Ремонт / Кухня и поставь срок завтра», «Отметь покупку краски купленной», «Создай проект Работа / Альбом / Видео».
На вопросы вроде «что осталось купить?» приходит ответ в переписке. На просьбу изменить записи появляется предложение там же: ответьте «да, применяй» или нажмите «Применить». «Нет» или «не надо» отменяет предложение. Новый вопрос отменяет предыдущий неподтверждённый план, чтобы случайное «да» не применило старую команду. Если запись успела измениться, старый план также не применяется.
Микрофон начинает диктовку; повторное нажатие отправляет сообщение в этот же разговор. Enter отправляет текст, Shift+Enter добавляет строку. Пока модель отвечает, можно набрать следующее сообщение или остановить ответ.
История и незаконченный текст чата сохраняются в этом браузере. При перезапуске старая команда не становится снова исполняемой. Записи и история диалога хранятся отдельно. Кнопка корзины очищает только диалог. Перед изменениями записей сохраняется копия; её можно скачать в настройках кнопкой «Копия до изменений помощника» и восстановить через импорт JSON.
Обычное окно добавления больше не открывается автоматически при старте. Сохранённый черновик и результат разбора доступны через кнопку «Продолжить» в верхней панели.
Запросы модели выполняются на этом компьютере, без API GPT. На старом оборудовании ответы могут занимать до нескольких минут.
Голосовой чат записывает реальный звук через MediaRecorder и распознаёт его локальным Whisper. После первоначальной установки интернет для расшифровки не требуется. В обычной форме быстрого добавления пока остаётся браузерное распознавание.
Сервис модели работает на компьютере; синхронизация записей по-прежнему выполняется через Supabase. PWA на телефоне не имеет прямого подключения к Ollama компьютера и сохраняет обычный интерфейс.
Локальный адрес и GitHub Pages имеют отдельные браузерные сессии. Один раз войдите в тот же аккаунт через «Облако», чтобы получить общую базу.

## Записи, разделы и проекты

В разделе «Записи и проекты» находятся все записи, включая обычные заметки и «На проверку». Есть поиск, сортировка, выбор типа и вложенного проекта. Фильтр родительского проекта включает подпроекты. Новый путь вводится через `/`: `Дом / Ремонт / Кухня`.
В любой карточке откройте «Настройки записи»: раздел, проект, родитель нового проекта, статус, приоритет, повтор, чеклист, заметки и исходная диктовка. В покупках количество и цена пересчитывают сумму. В «Деньгах» валюта выбирается отдельно; суммы разных валют не смешиваются.
Отметки школьных принадлежностей хранятся в общей записи-чеклисте «Школьные принадлежности» и синхронизируются. Старый список переносится при открытии школы.

## Добавление из чата проекта

В чате этого проекта можно написать: «Добавь в ежедневник: купить молоко» или «Добавь задачу: позвонить мастеру завтра».
При подключённом коннекторе Supabase помощник сохраняет структурированную запись в общую базу и проверяет результат.
Приложения получают её при следующей синхронизации. Обычное обсуждение не считается командой добавить запись.
Для работы компьютерного и телефонного приложений Codex не требуется; для выполнения команды через чат нужна активная сессия помощника с доступом к Supabase.

## Ярлык после переноса на другой компьютер

Из папки проекта запустите `powershell -File scripts\create-shortcut.ps1 -CopyToDesktop`.
Скрипт использует существующую иконку приложения и создаёт ярлык для установленного Chrome или Edge.

Файл `docs/PROJECT_STATE.md` — техническая памятка для продолжения разработки. Открытое справа окно с ним можно закрыть.

## Микрофон в чате

Первое нажатие запрашивает доступ и начинает настоящую аудиозапись. В чате видны таймер и уровень звука. Повторное нажатие завершает запись; надпись «Распознаю запись на компьютере» означает локальную расшифровку. Полученный текст отправляется в тот же разговор.

Если звука нет, откройте «Микрофон и синхронизация» и выберите вход звука. При запрете доступа, занятом устройстве или тишине показывается конкретная ошибка. При ошибке расшифровки аудио остаётся в памяти окна: его можно прослушать и распознать ещё раз. На сервере временный аудиофайл удаляется после обработки и в Supabase не отправляется.

Локальный движок на этом компьютере установлен в .maintenance/speech-runtime/. Для первоначальной настройки на другом компьютере: powershell -File scripts/setup-local-speech.ps1. Этот отдельный шаг устанавливает зависимости и речевую модель; обычный запуск ежедневника ничего не скачивает. Ollama продолжает отвечать за смысл диалога, Whisper — за речь.

Помощник на компьютере знает основные разделы: попросите, например, «Открой покупки» или «Перейди в календарь». Ответ на вопрос сам по себе не изменяет записи. Открытие отдельных записей и проектов через чат пока не поддерживается; данные отдельных разделов, которые не являются записями, в контекст чата пока не передаются.
