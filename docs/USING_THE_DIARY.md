# Ежедневник на компьютере, телефоне и в чате

Откройте `Ежедневник.lnk` в основной папке проекта или на рабочем столе.
Он запускает https://ver-dikt.github.io/DNEVNIK/ в отдельном окне Chrome.
Локальный сервер для повседневной работы не нужен. `start-dev.bat` и `start-local.bat` используются при разработке.

## Синхронизация

На компьютере и телефоне нажмите «Облако» и войдите в один аккаунт с одной почтой и паролем.
Записи сохраняются в Supabase. Изменения отправляются после редактирования, проверяются при возврате в приложение и примерно раз в минуту, пока окно видно.
Для обмена нужен интернет. При работе без сети записи остаются локально и синхронизируются после подключения.
Установленная PWA на телефоне и компьютерный ярлык используют один адрес приложения.

Второй телефон также может подключиться к этой базе под тем же аккаунтом. Два независимых аккаунта пока получают разные личные базы: приглашение партнёра и совместный доступ между аккаунтами ещё не реализованы.

## Локальная модель на компьютере

Ярлык `Ежедневник с ИИ` запускает установленную Ollama и локальную версию приложения на `http://127.0.0.1:3014`.
Первый запуск после переноса может потребовать сборку. Модели автоматически не скачиваются, облачные модели Ollama не предлагаются.
В окне «Локальный помощник» выберите модель и раздел контекста. Можно обсуждать записи или получить разбор с подтверждением перед сохранением.
Запросы модели выполняются на этом компьютере, без API GPT. На старом оборудовании ответы могут занимать до нескольких минут.
Сервис модели работает, пока запущен на компьютере; синхронизация записей по-прежнему выполняется через Supabase.
Локальный адрес и GitHub Pages имеют отдельные браузерные сессии. Один раз войдите в тот же аккаунт через «Облако», чтобы получить общую базу.

## Команды в чате проекта

В чате этого проекта можно написать: «Добавь в ежедневник: купить молоко» или «Добавь задачу: позвонить мастеру завтра».
При подключённом коннекторе Supabase помощник сохраняет структурированную запись в общую базу и проверяет результат.
Приложения получают её при следующей синхронизации. Обычное обсуждение не считается командой добавить запись.
Для работы компьютерного и телефонного приложений Codex не требуется; для выполнения команды через чат нужна активная сессия помощника с доступом к Supabase.

## Ярлык после переноса на другой компьютер

Из папки проекта запустите `powershell -File scripts\create-shortcut.ps1 -CopyToDesktop`.
Скрипт использует существующую иконку приложения и создаёт ярлык для установленного Chrome или Edge.

Файл `docs/PROJECT_STATE.md` — техническая памятка для продолжения разработки. Открытое справа окно с ним можно закрыть.
