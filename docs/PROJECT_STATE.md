## Работа

`start-dev.bat` — разработка, `start-local.bat` — production-просмотр по `http://127.0.0.1:3000`.
Для воспроизводимой установки используйте `npm ci`.
Проверки: `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`.
GitHub Actions проверяет код и публикует static export в GitHub Pages при push в `main`.

После обновления телефона закройте все окна PWA и откройте снова, либо примените предложенное обновление. Для общей базы войдите в один аккаунт Supabase на всех устройствах.

## Выполненные доработки

- Адрес Supabase в локальной конфигурации приведён к реальному проекту.
- Голосовая остановка запускает разбор. Уверенные пункты сохраняются, спорные показываются для проверки.
- Понимаются команды «В покупки», «В заметки», «В идеи», «В дела» и границы «новая запись».
- В карточке доступен выбор категории и повторный разбор исходного текста.
- Запись облака проверяет версию прочитанного состояния и повторяет объединение при конкурентном изменении.
- Повтор синхронизации работает после ошибки первого подключения; сообщения отражают фактическое сохранение в облако.

## Обновление интерфейса и локальный ИИ — 26 октября

- Светлая/тёмная стеклянная тема; карточка отношений показывает месяцы и дни, дату начала, ближайший месяц, годовщину и дни рождения.
- Календарь: месяц — 42 ячейки, неделя — 7 крупных дней, день — отдельная дата. Записи видны в окне выбранной даты; записи без даты не загромождают календарь. Фильтры владельца сохранены.
- Исправлена арифметика дат при часовом поясе Москвы и на концах месяца.
- В школе появился список школьных записей; диктовка понимает школьный контекст. В хотелках можно указать изображение вручную; вместо сломанной картинки показывается ссылка на магазин. Автополучение картинок на GitHub Pages по-прежнему ограничено отсутствием серверного API.
- `Ежедневник с ИИ.lnk` запускает отдельный локальный сервер на порту 3014 и установленную Ollama. Только установленные локальные модели, без скачивания и облачных GPT-запросов. Мегамозг не подключён.
- Разбор ИИ всегда предлагает предварительный просмотр перед сохранением. Чат сам базу не меняет. Для старой видеокарты используется CPU; скорость зависит от модели.
- Локальный адрес требует отдельного входа в тот же аккаунт Supabase. GitHub Pages и телефон не обращаются к Ollama компьютера.
- Next.js обновлён до 16.4.3. Проверены 152 теста, lint, TypeScript, production build и static export. Браузерная проверка: 375/768/1024/1440px, фильтры, даты, создание записи; 5 axe WCAG-аудитов без нарушений, ошибок браузера нет. Приватные сценарии и снимки — `.maintenance/`.
- Остаток npm audit: 6 предупреждений в цепочках инструментов сборки/тестов (2 moderate, 4 high), critical нет. Совместимое автообновление упирается во внутреннюю ошибку npm `edgesOut`; принудительное обновление основных версий не применялось.
