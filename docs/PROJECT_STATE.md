## Работа

`start-dev.bat` — разработка, `start-local.bat` — production-просмотр по `http://127.0.0.1:3000`.
Для воспроизводимой установки используйте `npm ci`.
Проверки: `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`.
GitHub Actions проверяет код и публикует static export в GitHub Pages при push в `main`.

После обновления телефона закройте все окна PWA и откройте снова, либо примените предложенное обновление. Для общей базы войдите в один аккаунт Supabase на всех устройствах.

## Выполненные доработки

- Адрес Supabase в локальной конфигурации приведён к реальному проекту.
- Голосовая остановка запускает разбор. Уверенные пункты сохраняются, спорные показываются для проверки.
- Понимаются команды «В покупки», «В заметки», «В идеи», «В дела» и границы «новая запись».
- В карточке доступен выбор категории и повторный разбор исходного текста.
- Запись облака проверяет версию прочитанного состояния и повторяет объединение при конкурентном изменении.
- Повтор синхронизации работает после ошибки первого подключения; сообщения отражают фактическое сохранение в облако.
