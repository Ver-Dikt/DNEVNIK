## Исправленные проблемы

- Настройки проекта были скрыты у задач, покупок, идей и рабочих записей. Теперь доступны для всех типов. Обычные заметки и неразобранные записи доступны в общем списке.
- Путь подпроекта не соответствовал реальному дереву. Добавлено построение узлов по каждому уровню пути, ссылки на конечный узел и фильтрация по поддереву. Одинаковые имена в разных ветках различаются; неоднозначный поиск не угадывает ветку.
- При переносе из работы оставался старый `domain`, из-за чего запись продолжала отображаться в работе. Поле обновляется вместе с разделом.
- Изменение типа записи оставляло несовместимый статус. Добавлена согласованная смена типа и статуса, включая покупки и хотелки.
- Школьные галочки были отдельными данными localStorage. Теперь это общий синхронизируемый чеклист с переносом старых отметок.
- Сумма покупки оставалась старой после изменения цены/количества; обзор денег смешивал валюты. Добавлены пересчёт и фильтр валюты.
- Выпадающие списки имели неоднозначные или отсутствующие подписи. Исправлен общий компонент Field и подписи в документах.
- Новые изменения во время облачного запроса могли ждать следующего опроса. Добавлена очередь повторного запуска; неизменившиеся снимки не вызывают UPDATE. Опрос активного окна — 15 секунд, изменения — после короткой задержки, online/focus — сразу.

## Управление через Ollama

Чат, создание записей из текста, команды создания/редактирования/переноса/завершения, создание вложенных проектов и предложение разбора выбранного раздела. Диктовка вводит команду, но сама не применяет изменения. Предварительный план проверяется по допустимым полям и существующим ID. При изменении ревизии запись не перезаписывается старым планом. Повторное создание по тому же плану отклоняется. Перед изменениями сохраняется копия, доступная для скачивания в настройках.

Проверен настоящий ответ установленной qwen2.5-coder:7b на перенос задачи в вложенный проект и смену приоритета. Голосовой UI проверен синтетическими событиями распознавания; физический микрофон не проверялся. Речь распознаёт браузер, которому может требоваться интернет. Ollama не обращается к GPT и не скачивает модели автоматически.

## Практические ограничения

На физическом телефоне остаётся проверить микрофон и принятие новой версии PWA. Для общей базы нужен вход в один аккаунт на каждом адресе; независимые аккаунты с приглашением партнёра пока не поддерживаются. Локальная модель на CPU может отвечать медленно; большой контекст нужно делить по разделам. Автозагрузка изображений товаров на статическом хостинге по-прежнему ограничена отсутствием серверного API.

Ранее обнаруженные 6 предупреждений npm audit в цепочках сборки/тестов остаются отдельной задачей обновления зависимостей; critical нет. Принудительные обновления основных версий не применялись после внутренней ошибки npm `edgesOut`. Полного теста входа в личный аккаунт с физического телефона этот отчёт не утверждает.
